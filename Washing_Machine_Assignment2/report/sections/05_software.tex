\subsection{Download and Run the Demo}
\begin{enumerate}
\item Open the repository link. Click \textbf{Code}, then \textbf{Download ZIP}.
Extract the ZIP and enter \code{Washing\_Machine\_Assignment2/}.
\item Open \code{output/}, then double click
\code{Washing\_Machine\_Simulator.html} to open it in Chrome, Edge or Firefox.
After downloading, the demo needs no Internet or installation.
\item Click \textbf{Reset bench}. Insert 20 cent and 50 cent. The state should
be Ready with 70 cent. Press RUN: Running, credit 0, timer 30:00.
\item In \textbf{Manual time} mode, advance 8 minutes using \textbf{+5 minutes} once and
\textbf{+1 minute} three times. Press PAUSE: 22:00 remains and wash is OFF.
Advance another 8 minutes, then press RUN: 14:00 remains.
\item Advance 14 minutes: the state returns to Standby. Start a new paid
cycle and press STOP twice. The first press keeps it running; the second ends it.
Start another cycle and click \textbf{Inject fault}: Error and wash OFF.
\end{enumerate}
Manual mode changes time only when a time button is clicked. Select
\textbf{Real time (1x)} to observe LED blinking. \textbf{Download log} exports
the events. GitHub displays HTML source; download it before running the demo.

\subsection{Repeat Tests or Open the Board Sketch}
For tests, install Python 3, Node.js and \code{g++}. Open a terminal inside
\code{Washing\_Machine\_Assignment2/} and run:
\begin{lstlisting}[language={},aboveskip=3pt,belowskip=3pt]
python3 tests/test_controller.py
\end{lstlisting}
The script checks the C++ logic, sketch adapter and browser model. In
\code{evidence/}, open \code{test\_console.txt} for the summary and
\code{test\_results.csv} for expected and actual values.

For an optional board check, open
\nolinkurl{firmware/washing_controller/washing_controller.ino} in Arduino IDE,
keeping \code{controller.h} beside it. Select Arduino UNO, Verify, then Upload
to a connected board. Serial Monitor uses 115200 baud: \code{1}, \code{2},
\code{5} insert coins; \code{r}, \code{p}, \code{s} control RUN, PAUSE, STOP.
The submitted evidence covers software tests and board compilation.
