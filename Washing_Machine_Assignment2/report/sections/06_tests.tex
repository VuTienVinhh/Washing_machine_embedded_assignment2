\section{Verification and Results}
\subsection{Software Tests}
Tests run the C++ controller with a virtual millisecond clock. Each scenario
checks expected states, credit, remaining time or outputs. No real 30 minute
wait is needed: the tests supply time values directly. These results verify
logic, not the accuracy of a physical board clock.

\midrule
Required behavior and edge cases & 25 scenarios passed; 145 expected fields checked.\\
Button handling & 13 checks passed for bounce, held presses, release and rollover.\\
Sketch adapter on computer & 15 checks passed with mocked Arduino inputs and outputs.\\
Browser model against C++ & All 5,001 steps matched in a seeded exploratory trace.\\
UNO R3 target build & Compiled with Arduino AVR Boards 1.8.6; 3,838 bytes of flash and 302 bytes of static RAM.\\
Browser controls & Coins, buttons, clock and fault controls passed; 10 captures saved.\\
\bottomrule
\end{tabularx}
